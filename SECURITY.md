# Security

For sensitive vulnerabilities, use GitHub's private vulnerability reporting on this
repository's Security tab. If it is unavailable, contact the maintainer through the
GitHub profile linked by the marketplace owner; do not post secrets publicly.
Include the affected version, minimal invented reproduction and expected impact.
For ordinary bugs, use the issue template. Remove credentials and private project data.

Only the latest released version receives fixes. Hooks are local guardrails, not a
sandbox: review commands, configuration and agent permissions before enabling merges.
